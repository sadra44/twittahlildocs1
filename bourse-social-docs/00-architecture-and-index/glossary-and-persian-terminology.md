# واژه‌نامه تخصصی و استانداردهای زبان فارسی
## Glossary & Persian RTL Terminology Standards

این سند استانداردهای واژگانی، برچسب‌های رابط کاربری (UI Labels) و مفاهیم زبان فارسی پلتفرم را طبق تصمیمات قطعی کارفرما تثبیت می‌کند.

---

## ۱. جدول واژگان محوری پلتفرم (Platform Core Terminology)

| مفهوم انگلیسی (English Concept) | شناسه فنی (Code Identifier) | اصطلاح رسمی فارسی (UI Display) | اصطلاحات منع‌شده | دلیل انتخاب و توضیحات |
| :--- | :--- | :--- | :--- | :--- |
| Tweet / Post | `Tweet` / `Post` | **توییت** | استاتوس، مقاله | واژه آشنا، صریح و جاافتاده برای کاربران شبکه‌های اجتماعی؛ کل محتوای متنی کوتاه تحت این عنوان شناخته می‌شود. |
| Publish action | `publish_action` | **ارسال** / **انتشار** | فرستادن، پستیدن | شفاف و کوتاه برای دکمه‌های کنشی. |
| Repost | `Repost` | **بازنشر** | ریتوییت | اصطلاح استاندارد زبان فارسی. |
| Quote Tweet | `QuoteTweet` | **نقل‌قول** | ریتوییت با نظر | ترکیب متن جدید با الصاق کارت توییت قبلی. |
| Like | `Like` | **پسندیدن** / **پسند** | لایک، علاقه‌مندی | دکمه: «پسندیدن»، شمارنده: «پسندها». |
| Comment / Reply | `Reply` | **پاسخ** | کامنت، نظر | برای مکالمات ذیل یک توییت. |
| Follow / Unfollow | `Follow` / `Unfollow` | **دنبال کردن** / **دنبال‌شده** | فالو کردن | دکمه استاندارد تعاملی دنبال کردن اشخاص یا نمادها. |
| Followers | `Followers` | **دنبال‌کنندگان** | فالوورها | لیست کاربرانی که شخص را دنبال می‌کنند. |
| Following | `Following` | **دنبال‌شوندگان** | فالویینگ‌ها | لیست اشخاصی که کاربر دنبال می‌کند. |
| Feed | `Feed` | **جریان توییت‌ها** / **فید** | تایم‌لاین، دیوار | تب‌های فید خانه: «مخصوص شما»، «همه»، «دنبال‌شده». |
| Cashtag | `Cashtag` | **کَش‌تگ نماد** (`$نماد`) | هشتگ سهم | علامت دلار پیش از نماد جهت تمایز سهم از موضوعات عامیانه. |
| Hashtag | `Hashtag` | **هشتگ** (`#موضوع`) | برچسب | هشتگ برای موضوعات عمومی. |
| Stock Symbol | `StockSymbol` | **نماد بورسی** | تیکر | نام تجاری سهم در بازار سرمایه (مانند «فولاد»، «خودرو»). |
| Full Company Name | `CompanyName` | **نام شرکت** | شرکت | نام کامل ثبتی شرکت (مانند «فولاد مبارکه اصفهان»). |
| Stock Page | `StockPage` | **صفحه نماد** | تالار سهم | صفحه اختصاصی تجمیع‌کننده توییت‌ها و نوار فشرده قیمت نماد. |
| Market Board Strip | `MarketBoardStrip` | **نوار قیمت** | تابلوی بورس | نوار کمکی و فشرده آخرین نرخ و درصد روز. |

## ۲. اصطلاحات کاربران و نشان‌های اعتبار (User Tiers & Badges)

| نوع کاربر | شناسه فنی | عنوان فارسی نمایشی | نشان گرافیکی | مفهوم و صلاحیت کاربری |
| :--- | :--- | :--- | :--- | :--- |
| **کاربر عادی** | `NORMAL_USER` | **سرمایه‌گذار / کاربر** | فاقد نشان | کاربر ثبت‌نام‌شده با پیامک OTP؛ سقف ۵۰۰ کاراکتر. |
| **تحلیل‌گر معتبر** | `VERIFIED_ANALYST` | **تحلیل‌گر تاییدشده** | تیک آبی (`#1D9BF0`) | تحلیل‌گر دارای گواهینامه حرفه‌ای بورس یا سابقه معتبر؛ سقف ۱۵۰۰ کاراکتر؛ دستیار هوش مصنوعی. |
| **نهاد مالی و حقوقی** | `FINANCIAL_INSTITUTION` | **نهاد مالی بازار** | تیک طلایی (`#D97706`) | کارگزاری‌ها، سبدگردان‌ها و صندوق‌های سرمایه‌گذاری دارای مجوز رسمی. |
| **ناشر رسمی بورسی** | `OFFICIAL_ISSUER` | **ناشر بورسی** | تیک زمردی (`#059669`) | نماینده رسمی امور سهام شرکت پذیرفته‌شده در بورس. |
| **ربات رسمی سامانه** | `MARKET_BOT` | **ربات اطلاع‌رسانی** | چرخ‌دنده خاکستری (`#6B7280`) | حساب‌های نرم‌افزاری اتوماتیک مانند ربات صبح‌نامه بورسینو (`@boursino_bot`). |
| **مدیر سیستم** | `ADMIN_MODERATOR` | **مدیر سامانه** | پنل مدیریت | دسترسی به کنترل کامل محتوا، کاربران و تنظیمات پویا. |

## ۳. برچسب‌های ناوبری اصلی (Navigation Labels)

### ناوبری پایین در موبایل (Bottom Navigation - راست به چپ):
1. **خانه (`/`):** فید اصلی با تب‌های «مخصوص شما»، «همه»، «دنبال‌شده».
2. **کاوش (`/explore`):** کشف توییت‌های برتر با فیلترهای پربازدید، پربحث و بیشترین لایک.
3. **پروفایل (`/profile`):** صفحه شخصی، توییت‌ها، پیوست‌ها، دنبال‌کنندگان و دنبال‌شوندگان.
4. **تنظیمات (`/settings`):** ویرایش مشخصات، امنیت، علایق و حالت شب.

### ناوبری بالای صفحه (Top App Bar):
* **لوگوی سامانه** (راست)
* **آیکون جستجو** (وسط)
* **آیکون اعلان‌ها** (چپ)
